# Explain

1. One short paragraph: the mental model (what it does and why it's built this way).
2. Walk the real code path with `file:line` references, in execution order.
3. Call out the non-obvious parts: invariants, gotchas, surprising design choices.
4. Stop. Go deeper only on request. No generic background the user didn't ask for.
